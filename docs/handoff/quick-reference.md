## Everyday tasks → where to go

| I need to… | Go to | Do this |
|---|---|---|
| Mark something **sold out** | Menu (`/admin/menu`) | Flip the **86 toggle** → public menu greys it instantly |
| **Change a price** | Menu | Edit price → **Save** (top bar) |
| Work the **order line** | Orders (`/admin/orders`) | received → preparing → **ready** (ready notifies the guest) |
| **Refund** an order | Orders | Refund (full/partial) — restores stock if not yet made |
| **Seat / clear** a table | Reservations (`/admin/reservations`) | Day view → seat → clear → turn |
| Add a **walk-in** | Reservations | Add walk-in on the timeline |
| Edit **website text/photos** | Content (`/admin/content`) | Edit → Save → reload public page |
| Reply to **bad feedback** | Feedback (`/admin/feedback`) | Respond to the alert → mark resolved |
| Read **sales / tax** (Owner) | Reports (`/admin/reports`) | Pick a period → export for bookkeeper |
| **Rotate a key** (Owner) | Settings (`/admin/settings`) | Paste key → Save → **Test connection** (green) |
| **Add staff** (Owner) | Users (`/admin/users`) | Invite → set role |

## Roles at a glance
- **Owner:** everything (money, settings, users).
- **Manager:** operations, menu, reservations, feedback. No settings/users/reports money.
- **Staff:** order queue + reservations only. No financials.

## Notifications
- Guests get **email** confirmations/ready alerts now. **SMS** turns on later
  (carrier approval) — no action needed from you.

## "Is this broken?" — usually not
- **Locked out after wrong passwords?** Security lockout — wait ~15 min, retry.
- **Menu item won't add for a guest?** It's 86'd or outside its day-part. Check Menu.
- **Wallet (Apple/Google Pay) button missing?** Pending Stripe domain setup — tell Renato.

## If a guest presents an **old Square gift card**
- Handle per the current cutover instruction (ask the Owner). Do **not** turn
  anyone away — note the card + balance and flag it. (Square balances are handled
  per the cutover plan; see Renato.)
